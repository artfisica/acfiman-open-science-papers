# Declaración para la carta de presentación

Texto para revisar antes del envío:

Durante la preparación de los manuscritos utilizamos ChatGPT/Codex para apoyar la búsqueda documental, la organización de borradores, la revisión lingüística y el desarrollo del flujo de compilación LaTeX. La asistencia incluyó propuestas de texto y código. Nos corresponde verificar las fuentes, los datos, las interpretaciones y la versión final; las herramientas no figuran como autores. Adaptaremos esta declaración a las instrucciones de la revista y completaremos los detalles de uso que solicite.
